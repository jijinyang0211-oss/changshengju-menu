# 长生居 · 私房菜

一个精致的家宴菜单预订系统。中式暗金水墨风格，带月洞门开场动画，食客可在线浏览菜品、选择日期时段、提交预订订单；店主可在管理后台查看订单并备菜。

> 人间烟火气，最抚凡人心。

## 功能特性

- 🎬 月洞门开场动画：点击「推门而入」穿门入场，展示「长生居」品牌名
- 🍽️ 完整菜单：64 道菜品，按「冷菜 → 炒菜 → 主食 → 汤品 → 特色」分类展示，带插图与食材清单
- 📅 日历 + 时段预订：日历选择日期（过去日期自动禁用），午市 / 晚市时段一键选择
- 🧺 点菜购物篮：菜品按分类分组展示，支持增删、实时统计
- ✅ 确认订单：提交前弹出确认单，展示全部菜品与备注
- 📋 我的订单：随时查看历史订单、备注与状态，支持再次编辑预订（再次预订）
- 📝 忌口备注与「想吃但没有的菜」：食客可留言想吃的菜，店主可研究新菜
- 🔧 管理后台：订单列表、菜品分组带图展示、备菜清单（按菜品汇总食材）、确认 / 完成 / 删除订单
- 📱 移动端适配：品类保持左侧分栏，卡片随屏幕自适应

## 技术栈

- 后端：Node.js + Express（原生 JS，无构建步骤）
- 数据：本地 JSON 文件（`data.json`）持久化
- 前端：原生 HTML / CSS / JS，SVG 手写动画，毛笔字体（马善政楷书）本地引入

## REST API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/menu` | 获取菜单与分类 |
| GET | `/api/orders` | 获取全部订单 |
| POST | `/api/order` | 创建订单 |
| PUT | `/api/order/:id` | 更新订单（再次预订） |
| POST | `/api/order/:id/status` | 更新订单状态 |
| DELETE | `/api/order/:id` | 删除订单 |
| POST | `/api/dish-image` | 设置菜品图片 |

## 数据说明

数据拆分为两个文件：

- `menu.json`：`menu`（菜品数组，含 `id / name / category / subCategory / description / tags / image / ingredients`）与 `config`（主厨名称与欢迎语）
- `orders.json`：`orders`（订单数组，含预订人、日期时段、人数、忌口、想吃的菜、菜品明细与状态）

`orders.json` 不入版本库，仅在服务器本地持久化，避免部署时覆盖线上订单。
